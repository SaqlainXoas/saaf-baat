# Style Notes (Apple-minimal + warm)

## Intent
- **Less UI, more clarity**: every pixel earns its spot.
- **Warm neutrality**: calm background + subtle brand gradient to feel human, not “tool-y”.
- **Approachable language**: “Certain / Debated” instead of “confidence scores”.
- **Deck, not feed**: a small number of essential stories, presented like cards you can finish.

## Information hierarchy (Home)
1. Greeting + context (city / date / “essential stories”)
2. Card deck (top story fully readable; next stories softly behind)
3. “Caught up” calm closure

## Components to keep consistent
- Rounded corners, hairline borders, soft shadow
- Impact pill (WALLET/COMMUTE/SAFETY...) as the “top-left label”
- Consensus Engine blocks:
  - “What’s agreed” (green tint)
  - “What’s debated” (warm tint)

## Copy tone
- Calm, direct, non-judgmental.
- Avoid “breaking”, “shocking”, “must read”.
